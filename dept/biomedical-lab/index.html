    1. 이 직업(임상병리사·방사선사·치과위생사)이 하는 일을 정확히 알고 있나요?

    왜 묻나 직업 이해입니다. 을지대 EU면접형의 계열(전공) 적합성(계열에 대한 관심과 이해), 청주대 교과면접의 모집단위 적합성(전공 적성 및 비전)이 이 질문입니다. 업무 범위와 면허 경로를 아는지 봅니다.

    2. 작은 실수가 큰 결과를 낳는 일인데, 정확성을 지킨 경험이 있나요?

    답변 구조 경험 하나 → 실수가 날 뻔한 지점 → 내가 만든 확인 방법 → 결과 → 직업과 연결

    3. 검사를 앞둔 환자가 불안해하면 어떻게 하겠습니까?

    답변 구조 불안의 이유를 묻는다 → 무엇을 왜 하는지 쉬운 말로 설명 → 환자가 고를 수 있는 것 안내 → 경험 하나

    답변 예시먼저 무엇이 걱정되시는지 여쭤보겠습니다. 바늘이 무서운지, 예전에 어지러웠던 적이 있는지에 따라 할 일이 다르기 때문입니다. 그다음 몇 번 찌르고 몇 분 걸리는지 미리 말씀드리고, 누워서 받을 수 있다는 것도 안내하겠습니다. 요양원 봉사에서 어르신이 혈압 측정을 거부하실 때 순서를 먼저 설명드렸더니 팔을 내주신 적이 있습니다.

    답변 구조 내 성취(강한 과목) → 약한 과목과 보완 → 학생부 탐구 하나의 원리 → 전공과 연결

    답변 예시생명과학Ⅰ은 2등급, 화학Ⅰ은 3등급입니다. 화학은 몰 농도 계산이 약해서 방학 동안 문제집 한 권을 다시 풀고 있습니다. 2학년 때 혈액형 판정 원리를 탐구했는데, 적혈구 표면의 항원이 맞는 항체를 만나면 엉겨 붙는 반응을 이용한다는 것을 알았습니다. 임상병리학에서 배우는 면역 검사가 이 원리에서 시작한다는 점이 흥미로웠습니다.

    주의 약한 과목을 숨기지 말고 보완 계획을 말하세요. 학생부에 적힌 탐구는 원리까지 설명할 수 있어야 합니다.

    5. 이 분야의 기술 변화(AI 판독·자동화)는 직업에 어떤 영향을 줄까요?

    답변 구조 변화 인정 → 줄어드는 일 → 남거나 늘어나는 일(이상 결과 판단, 장비 정확도 관리) → 내가 준비할 것

    답변 예시검사 장비가 자동화되면서 사람이 손으로 하던 분석은 줄어들 것이라고 생각합니다. 하지만 장비가 낸 결과가 이상할 때 검체 문제인지 장비 문제인지 판단하고, 장비가 정확한지 매일 확인하는 일은 사람이 책임져야 합니다. 그래서 임상병리사의 역할이 검사하는 사람에서 결과를 검증하는 사람으로 바뀐다고 봅니다. 대학에서 통계와 데이터 분석도 함께 공부하겠습니다.

    • 9~10일차: 질문 4와 5(기초 과목, 자동화)를 정리합니다. 진단검사 자동화 관련 기사 하나를 읽고 바뀌는 역할을 한 문장으로 말해 봅니다.

    • 전날: 새 답변을 만들지 않습니다. 을지대는 교복 대신 단정한 사복 착용이 명시돼 있고, 청주대는 면접 안내에 복장 규정이 따로 없지만 단정한 사복이 안전합니다. 신분증·수험표를 챙기고 일찍 잡니다.

    임상병리학과·방사선학과·치위생학과 면접 자주 묻는 것들

    임상병리학과 면접에서 의학 지식 문제를 내나요?

    을지대 EU면접형은 제출서류를 바탕으로 진위를 확인하는 서류기반 면접이고, 청주대 교과면접은 적합성·학업성·인성을 보는 면접입니다. 문제 풀이는 없지만 학생부에 적은 탐구의 개념은 설명할 수 있어야 합니다.

    임상병리사와 방사선사, 치과위생사는 어떻게 다른가요?

    임상병리사는 혈액·소변·조직 같은 검체를 검사하고, 방사선사는 엑스레이·CT 같은 영상 검사와 방사선 치료를 맡고, 치과위생사는 스케일링과 구강보건교육 같은 예방 처치를 합니다. 셋 다 학과 졸업 후 국가시험으로 면허를 받는 보건의료 직업입니다.

    수능 최저가 있나요?

    을지대 EU면접형과 청주대 교과면접전형(항공운항학과 제외) 모두 없습니다. 대학과 전형마다 다르니 지원 전형별로 확인하세요.

    을지대 의정부캠퍼스 임상병리학과도 면접은 어디서 보나요?

    을지대 EU면접형 면접은 11월 21일(토) 성남캠퍼스에서 시행한다고 모집요강에 적혀 있습니다. 의정부캠퍼스 모집단위 지원자도 장소와 이동 시간을 미리 확인하세요.

    임상병리학과 면접 복장은?

    을지대는 모든 지원자가 교복 대신 단정한 사복을 입어야 하고, 이름·수험번호·출신고교·부모 직업을 말하면 안 되는 블라인드 면접입니다. 청주대는 모집요강 면접 안내에 복장 규정이 따로 없지만 단정한 사복이 안전합니다.

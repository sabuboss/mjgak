# 블로그 원고 독립 검수 지침 (2026-10-12)

ROOT = `C:\Users\nkkim\my-html-project\mjgak`. 당신은 **그 원고를 쓰지 않은 검수자**다. 작성자의 보고나 rich json 을 믿지 말고 원문 PDF에서 직접 다시 확인한다.
면접은 수험생에게 아주 중요하다. 틀린 날짜·숫자 하나가 실제 피해로 이어진다. "수정할 일이 없게" 하는 것이 목표다.

## 할 일
1. 원고(`docs/promo/naver-NN-*.md`)를 처음부터 끝까지 읽고, **사실 주장**을 전부 목록으로 뽑는다:
   숫자(인원·배수·비율·점수·분·쪽수), 날짜·요일·시각, 전형·모집단위 이름, 평가 항목과 배점, 자격 조건, 결격·불합격 조건, 복장·블라인드 규정, 수능 최저, 복수지원 규정, 인용문("…").
2. 각 주장을 원문 PDF(`docs/promo/img/src/m_<대학명>.pdf` 등, 원고 하단 ※ 인용 안내에 적힌 자료)에서 pymupdf 로 다시 찾아 대조한다. 표가 이미지라 텍스트가 안 나오면 그 쪽을 렌더링해서(`page.get_pixmap(dpi=150)` → png → Read) 눈으로 확인한다.
   - 요일은 달력으로도 검산한다(`python -c "import datetime;print(datetime.date(2026,10,31).strftime('%a'))"`).
   - 쪽수는 인쇄 쪽 번호 기준(원고 표기와 같은 기준인지 확인).
   - 인용문은 원문과 글자 단위로 비교(띄어쓰기 차이는 허용).
3. 근거 없는 추론·일반화 문장("~일 가능성이 크다", "대부분의 대학은 ~" 등)과 시간이 지나면 틀리는 시사 단정이 있으면 표시한다.
4. 답변 예시에 블라인드 위반 소재(학교 이름, 부모 직업, 수상명, 공인어학점수)가 있는지, 대괄호 빈칸이 남았는지 본다.
5. 원고의 캡처 PNG(작업용 메모의 이미지 목록)를 전부 Read 로 열어: 다른 전형·대학 내용이 섞였는지, 위·아래 글자가 잘렸는지, 푸터 요약 문구가 본문·원문과 일치하는지 본다.
6. 사이트 링크(`https://mjgak.com/...`) 경로가 `site/dist/` 에 실제로 있는지 확인한다.

## 고치는 방법
- **명백한 사실 오류**(원문과 다른 숫자·날짜·요일·쪽수, 틀린 인용)는 원고를 직접 고친다. 캡처 푸터 문구가 틀리면 해당 jobs 스크립트의 note 를 고치고 그 이미지만 다시 만든다(promo_style.py 수정 금지).
- 근거 없는 추론 문장은 삭제하거나 원문으로 확인되는 사실 문장으로 바꾼다.
- 판단이 필요한 것(원문끼리 모순, 원문에 없는 정보)은 고치지 말고 보고만 한다.
- 원고를 고쳤으면 `cd docs/promo/paste && PYTHONIOENCODING=utf-8 python make_paste.py ../naver-NN-*.md` 로 붙여넣기 페이지를 다시 만든다.
- git commit/push 금지. site/ 아래·다른 원고 수정 금지. TLS 검증 끄기 금지. 네이버 접속 금지.

4. 이미지 점검 결과

## 넣을 곳
`site/content/rich/univ/<code>.json` 에 최상위 키 두 개를 **추가**한다. 기존 키·값·순서는 건드리지 않는다(`checked` 도 그대로).

```json
"after": {
 "final": "12/11(금) 17:00 · 입학처 홈페이지",
 "register": "12/14(월)~12/16(수) 16:00 · 예치금 등록",
 "extra": "충원 합격 발표 12/17(목)~12/23(수) 21:00 · 차수별 홈페이지 발표, 마지막 차수는 전화 개별 통보",
 "source": "2027학년도 수시모집요강 6쪽(전형 일정)"
},
"dayof": {
 "arrive": "면접 시작 30분 전까지 대기실 입실 · 개인별 고사 시간은 1단계 합격자 발표 때 공지",
 "bring": "수험표, 신분증(주민등록증·여권·청소년증 등)",
 "phone": "대기실 입실 때 휴대폰 등 전자기기 제출",
 "blind": "교복 착용 금지 · 이름·수험번호·출신고교명 말하면 안 됨",
 "other": "면접 종료 후 바로 퇴실, 대기실로 돌아갈 수 없음",
 "source": "2027학년도 수시모집요강 46쪽(면접 유의사항)"
}
```

- **final**: 수시 최종 합격자 발표일(시각·방법이 있으면 함께). 전형마다 다르면 `"학생부종합 OO전형: 12/11(금) · 학생부교과 OO전형: 12/4(금)"`처럼 전형 이름과 함께. 면접 없는 전형은 빼도 된다.
- **register**: 최초 합격자 등록(예치금·문서 등록) 기간.
- **extra**: 충원(추가) 합격자 발표·등록 일정과 마감. 차수별 날짜가 있으면 처음과 마지막만, 통보 방법(홈페이지·전화).
- **dayof** 각 키: 원문의 면접 유의사항·고사 당일 안내에 있는 것만. arrive(입실·집합 시간, 지각 처리), bring(준비물), phone(휴대폰·전자기기), blind(블라인드·복장·말하면 안 되는 것), other(대기·이동·퇴실·기타 규정).
- 원문에 없는 키는 **넣지 않는다**(빈 문자열도 금지). 두 묶음 모두 원문에 아무것도 없으면 그 묶음을 `{}` 로 둔다.
- 값은 한 키당 120자 이내, 짧은 명사구. 날짜는 `12/11(금)` 형식이고 **요일은 달력으로 검산**한다: `python -c "import datetime;print(datetime.date(2026,12,11).strftime('%a'))"`. 원문 요일과 달력이 다르면 보고한다.
- source 는 **인쇄 쪽 번호**(PDF 쪽과 다르면 인쇄 쪽). 여러 쪽이면 `"6쪽(전형 일정)·46쪽(면접 유의사항)"`.
- 이미 끝난 날짜도 그대로 적는다. "~할 예정입니다" 같은 추측·일반화 문장 금지. 원문이 "추후 공지"면 `"추후 홈페이지 공지(모집요강 기준)"` 로 그대로 적는다.

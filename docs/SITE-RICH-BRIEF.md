저장소: `C:\Users\nkkim\my-html-project\mjgak` (ROOT). 오늘 2026-10-10. 2027학년도 수능 2026-11-19(목).
목표: 사이트(mjgak.com)의 빈칸 템플릿 페이지를 블로그 글 수준(확인된 사실 + 완성 예시 답변)으로 끌어올린다.

## 0. 공통 규칙 (가장 중요)

1. **사실은 확인한 것만.** 대학·전형의 숫자·날짜·비율·배수·인원·면접 시간·평가 항목·최저·공개 질문은 아래 둘 중 하나에서만 가져온다.
   - 블로그 원고 `ROOT/docs/promo/naver-NN-*-v*.md` 의 "올해는 어떻게 보나 / 언제 보나 / FAQ" 문단 (이미 PDF 로 검증된 문장)
   - 모집요강 PDF `ROOT/docs/promo/img/src/m_<대학명>.pdf` (또는 cau.pdf, ulsan.pdf, kyungnam.pdf, nambu.pdf) 를 pymupdf 로 직접 읽은 텍스트
   못 찾으면 쓰지 않는다. 추정·일반화 금지.
2. **복장**: "교복 금지"는 그 대학 면접 안내에 명시된 경우만(광운 p46, 명지 p88, 아주 p54, 덕성 p74, 국민, 성신, 을지, 동국 등). 경희·숭실은 면접 안내에 복장 규정 없음.
3. **예시 답변은 완성된 문장**(대괄호 빈칸 금지). 가상의 학생 경험, 120~220자, "~입니다/했습니다" 말투. 실존 인물 이름·근거 없는 통계 금지.
4. 문체: 짧은 문장, 존댓말. 이모지 금지.
5. **각자 맡은 파일만** 만든다. 다른 작업자 파일, `site/build.py`, `site/templates/`, 기존 `site/content/*.json` 은 고치지 않는다(예외는 각 작업 설명에 명시).
6. git commit/push 금지.
7. JSON 은 UTF-8, `ensure_ascii=False`, 들여쓰기 1. 만들고 나서 `python -c "import json;json.load(open(...,encoding='utf-8'))"` 로 검증.
8. PDF 는 `PYTHONIOENCODING=utf-8` 로 실행, MuPDF 경고는 무시. 회사망이라 CDN 다운로드는 TLS 오류가 날 수 있음 — 막히면 보고만 하고 넘어간다.

## 3. 공통·계열·유형 예시 — `ROOT/site/content/rich/examples.json`

```json
{
 "common": {"self-intro-1min": "완성 예시 답변", "...": "..."},
 "majors": {"humanities": ["질문1 예시", "질문2 예시", "..."], "social": ["..."]},
 "types": {"GEN-01": "완성 예시 답변", "...": "..."}
}
```
- common: `common.json` questions 48개 slug 전부. majors: `majors.json` 각 계열 questions 순서대로. types: `type_answers.json` answers 의 키 전부.
- 기존 템플릿(answer)의 구조를 그대로 따르되 빈칸을 가상의 구체적 경험으로 채운 완성 답변. 학생마다 다양하게(학과·활동이 겹치지 않게).

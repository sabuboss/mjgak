    모의 면접 연습

    질문을 무작위로 뽑아 생각 15초 → 답변 60초로 소리 내어 연습합니다. 녹음하면 바로 다시 들을 수 있고, 녹음 파일은 이 기기 브라우저 안에서만 재생되며 서버로 보내지 않습니다.

    질문 묶음을 고르고 시작을 누르세요.

    준비되면 질문 뽑기를 누르세요.

    대기0:15
    답변 예시와 주의할 점 보기 (답한 뒤에 보세요)

    마이크를 쓸 수 없어 녹음 없이 진행합니다. 휴대폰이라면 브라우저의 마이크 권한을 확인하세요.

    이렇게 연습하세요

    1. 생각 15초 동안 결론 한 문장만 정합니다. 답을 외워 둔 문장을 떠올리는 시간이 아닙니다.
    2. 답변 60초는 결론 → 경험 → 배운 점 → 연결 순서로 말합니다. 답변 구조 자세히
    3. 녹음을 다시 들으며 세 가지만 확인합니다. 60초를 넘겼는지, "음…"이 몇 번 나왔는지, 학교 이름·성적·수상처럼 블라인드 면접에서 말하면 안 되는 말이 있었는지.
    4. 답한 뒤에 예시를 열어 내 답과 비교합니다. 예시를 먼저 보면 내 말이 아니라 예시를 따라 하게 됩니다.

    질문은 이 사이트의 학과별·공통 질문과, 대학이 모집요강에 공개한 면접 질문 예시에서 뽑습니다. 녹음은 페이지를 닫으면 사라집니다.

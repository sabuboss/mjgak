면접 방식과 특징

학생부종합 일부 전형은 서류 기반 면접을 실시해 왔고, 일부 모집단위 문항이 공개된 해도 있습니다. 모집요강에서 확인하세요.

  • 서류 활동의 진위
  • 전공 적합성
  • 인성

대진대학교 맞춤 예상 질문 5개

이 사이트가 대학 특성에 맞춰 만든 예상 질문입니다. 실제 기출이 아니며, [대괄호]는 본인 경험으로 바꾸세요.

1. 학생부 활동 하나의 과정을 설명해 보세요.

왜 묻나 서류 기반 면접.

[활동] → [과정] → [결과] → [배운 점].

준비 팁 구조대로. 대진대 기출 페이지도 확인.

2. 대진대의 이 학과를 택한 이유는?

왜 묻나 지원 동기.

[학과 특징]이 제 [관심]에 맞습니다.

준비 팁 구체적.

3. 어려움을 극복한 경험은?

왜 묻나 회복탄력성.

[상황] → [행동] → [결과] → [배운 점].

준비 팁 구체 사례.

4. 협업 경험은?

왜 묻나 인성.

[상황] → [행동] → [결과].

준비 팁 구체 사례.

5. 진로와 계획은?

왜 묻나 진로.

[진로]와 [계획]입니다.

준비 팁 구체적.

이 대학 면접을 준비할 때

  • 제시문 기반 면접은 제시문을 읽는 시간이 짧습니다. 기출 제시문으로 '요약 → 비교 → 입장' 순서를 시간 재며 연습하세요.
  • 수학·과학 문항은 이 사이트의 텍스트에서 수식이 빠져 있을 수 있습니다. 반드시 출처 PDF에서 원문을 확인하세요.
  • 서류 기반 면접·인성면접 문항은 공개되지 않습니다. 공통 질문과 유형별 질문, 학과별 질문으로 준비하세요.

이 페이지의 문항은 입학처 공개 자료를 구조화한 것으로, 원문 PDF는 싣지 않습니다. 각 문항의 출처 링크에서 원문을 확인하세요. 잘못 옮겨진 문항은 문의로 알려 주세요.
